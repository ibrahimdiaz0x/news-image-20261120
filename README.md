## Stories

All six stories happened, or were first reported, on Friday 20 November 2026:

1. GTA VI's record first day — Sensor Tower estimate via Reuters.
2. Anthropic's record IPO debut — Wall Street Journal, Reuters, CNN.
3. Drone raid damages Kyiv embassies — AFP, Kyiv24.
4. Houthi raid damages Riyadh's PIF Tower — Reuters.
5. Migrant boat capsizes off Senegal — Reuters.
6. Brazil moves to a five-day week — Particle News, Poder360.
